# Elden Ring Data Science Project

## Opis projekta

Projekt iz kolegija Osnove podatkovne znanosti temeljen na skupu podataka o boss i mini-boss protivnicima iz igre Elden Ring.

Cilj projekta bio je prikupiti i organizirati podatke te ih analizirati pomoću Python biblioteka za obradu i vizualizaciju podataka.

## Sadržaj repozitorija

* Jupyter Notebook (`.ipynb`) s analizom podataka i vizualizacijama
* PDF dokument s prikazom projekta
* Dataset korišten u analizi

## Korištene tehnologije

* Python
* pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## Analiza

Projekt uključuje:

* učitavanje i obradu podataka
* filtriranje i rad s podacima pomoću pandas biblioteke
* analizu boss i mini-boss podataka
* grafičke vizualizacije
* analizu odnosa između varijabli
* osnovnu korelacijsku analizu
